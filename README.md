# Learning-Curve Analysis of k-NN vs LDA

## Project Overview
This project compares two machine learning classification algorithms:
- k-Nearest Neighbours (k-NN)
- Linear Discriminant Analysis (LDA)

The study analyzes how different training-set sizes and noise levels affect their classification performance.

## Datasets
1. Iris Dataset
2. Wine Recognition Dataset
3. Breast Cancer Wisconsin (Diagnostic) Dataset

## Objectives
- Compare k-NN and LDA.
- Study the effect of training-set size.
- Analyze the impact of noise on model performance.
- Evaluate performance using multiple metrics.
- Use cross-validation and repeated experiments for reliable results.
